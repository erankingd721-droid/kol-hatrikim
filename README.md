# כל הטריקים

אתר שמציג כל יום את הטריקים הכי טובים במיינקראפט מ-YouTube Shorts ומ-TikTok.
בוט רץ לבד כל יום לפנות בוקר, מוצא את הסרטונים ומעלה אותם לאתר. העמוד הראשי מציג את כל הטריקים מ-7 הימים האחרונים, והחדשים מסומנים. אין שרת לתחזק: הכל רץ בחינם על GitHub.

## מה יש כאן

| קובץ | מה הוא עושה |
| --- | --- |
| `index.html`, `assets/` | האתר עצמו. שלושה עיצובים (מיינקראפט, רעלי, ארקייד) עם כפתור החלפה למעלה. |
| `bot/bot.mjs` | הבוט. סורק, מסנן וכותב את הטריקים ל-`data/`. |
| `bot/config.json` | מילות החיפוש, הקטגוריות, כמה טריקים בכל סריקה, כמה ימים להציג בעמוד הראשי ומה לסנן החוצה. |
| `bot/youtube-links.txt` | קישורי YouTube שאתם רוצים שיעלו לאתר. עובד גם בלי מפתח API. |
| `bot/tiktok-links.txt` | קישורי TikTok שאתם רוצים שיעלו לאתר. |
| `data/` | מה שהבוט מצא: `latest.json` (העמוד הראשי: 7 הימים האחרונים), `weeks/` (קובץ לכל יום, השם נשאר מהגרסה השבועית), `thumbs/` (תמונות של TikTok). |
| `.github/workflows/weekly-bot.yml` | מריץ את הבוט כל יום ומעלה את האתר. |

## הפעלה (פעם אחת)

1. **מעלים ל-GitHub.** יוצרים מאגר חדש (Public) ודוחפים אליו את התיקייה הזאת לענף `main`.
2. **מדליקים את האתר.** במאגר: Settings ← Pages ← Source: **GitHub Actions**.
3. **מפתח ל-YouTube** (חינם):
   1. נכנסים ל-[Google Cloud Console](https://console.cloud.google.com/), יוצרים פרויקט חדש.
   2. APIs & Services ← Library ← מפעילים את **YouTube Data API v3**.
   3. APIs & Services ← Credentials ← Create credentials ← **API key**. כדאי להגביל אותו ל-YouTube Data API v3.
   4. במאגר ב-GitHub: Settings ← Secrets and variables ← Actions ← New repository secret, בשם `YOUTUBE_API_KEY`, ומדביקים את המפתח.
4. **סריקה ראשונה.** בלשונית Actions בוחרים **Daily bot + site** ← Run workflow. אחרי דקה-שתיים האתר מתמלא.

מכאן הבוט רץ לבד כל יום ב-00:00 UTC (02:00–03:00 בישראל). GitHub לפעמים מאחר בכמה דקות.

בלי מפתח YouTube הבוט עדיין עובד, אבל רק עם קישורים שהוספתם ל-`bot/youtube-links.txt`. עם מפתח הוא גם מחפש לבד.

## באתר

כל כרטיס מראה תמונה אמיתית מהסרטון. לחיצה עליה מנגנת את הסרטון בתוך הכרטיס (הנגן הרשמי של YouTube או של TikTok), ורק סרטון אחד מתנגן בכל פעם.

## TikTok

ל-TikTok אין דרך פתוחה לחפש סרטונים, אז יש שתי אפשרויות:

- **קישורים ידניים (עובד מיד):** מוסיפים קישורים ל-`bot/tiktok-links.txt`, שורה לכל סרטון. הבוט מושך את הכותרת, היוצר והתמונה דרך ה-oEmbed הרשמי של TikTok ומעלה אותם בסריקה הבאה.
- **חיפוש אוטומטי:** דרך [TikTok Research API](https://developers.tiktok.com/products/research-api/). צריך לבקש גישה, ו-TikTok מאשרים בעיקר חוקרים ואקדמיה. אם מקבלים אישור, מוסיפים את הסודות `TIKTOK_CLIENT_KEY` ו-`TIKTOK_CLIENT_SECRET` והבוט יתחיל לחפש לבד לפי ההאשטגים ב-`config.json`. החלק הזה עוד לא נבדק מול TikTok אמיתי.

## איך הבוט מחליט מה עולה

- רק סרטונים מהיומיים האחרונים, עד 3 דקות, ובחיפוש בטוח (`safeSearch=strict`).
- הכותרת או התיאור חייבים להזכיר מיינקראפט וגם טריק/האק/טיפ/סוד.
- סרטונים על צ'יטים (hacked client, xray וכו') מסוננים החוצה. הרשימה ב-`exclude`.
- ביוטיוב צריך לפחות 1,000 צפיות.
- סרטון שכבר עלה ביום קודם לא עולה שוב.
- עד 36 טריקים חדשים בכל סריקה, עד 24 מכל פלטפורמה, לפי מספר הצפיות. קישורי TikTok שהוספתם ידנית תמיד עולים ראשונים.
- הקטגוריה (רדסטון, חוות, בנייה, PvP, הישרדות, סודות) נקבעת לפי מילים בכותרת. אפשר לשנות ב-`config.json`.

## במחשב

```bash
node dev/serve.mjs
```

ואז נכנסים ל-http://localhost:8080. כדי לראות את האתר עם טריקים לדוגמה: http://localhost:8080/?demo=1

להריץ את הבוט בלי לשמור כלום (רק לראות מה הוא היה מעלה):

```bash
YOUTUBE_API_KEY=המפתח_שלכם node bot/bot.mjs --dry
```

צריך Node 20 ומעלה. אין חבילות להתקין.
